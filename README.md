# 🚗 Vehicle Rental System – Frontend

Frontend web application for a vehicle rental system.

## 🧠 Project Goal

This project is part of my portfolio to demonstrate my growth from **Junior to Mid React Developer**, applying best practices, clean architecture, and incremental development.

## 🛠 Tech Stack

- React 18
- TypeScript
- Vite
- React Router
- Axios
- Tailwind / CSS Modules
- Vitest + Testing Library

## 🧩 Features (planned)

- Vehicle listing
- Vehicle rental flow
- Authentication (simulated)
- Global state management
- Testing
- Performance optimizations

## 🚀 Development Strategy

The project is developed **branch by branch**, each one representing a new level of complexity and responsibility.
